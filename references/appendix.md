## 附加规则(让方法在团队里跑得动)

*Musk 自己称这些为 corollaries。它们不是第 6 步,是前提。*

| 规则 | 要点 |
|---|---|
| 管理者必须动手 | 技术管理者必须有实操经验;软件主管至少 20% 时间写代码。不写代码的主管,没能力质疑软件需求 |
| 警惕"同志情谊" | 太熟会让人不敢质疑同事的工作 —— 而质疑正是减法第 1 步 / 探索第 1 步的全部 |
| 可以错,别自信地错 | "It's OK to be wrong. Just don't be confident and wrong." |
| 跳过一级 | 有问题时别只找你的经理,去找经理下面那一层 |
| 唯一的铁律是物理定律 | 指**不可推翻**。法律 / 合规是"不可无视但可变更",不等于建议 |
| 疯狂的紧迫感 | "A maniacal sense of urgency is our operating principle." |

## 边界(知道它不覆盖什么)

- **两种模式不是两等分,价值都集中在开头。** 减法模式价值在"质疑 + 删除"(改的是"你在解哪道题"),探索模式价值在"参照系 + 证伪判据"(改的是"你找什么")。
- **都是循环,不是一次性流程 —— 但循环有边界。** 目标未达成期间,跑完一轮回到开头重来;**目标达成 / 被证伪 / 撞上预算闸 → 停**。停下之后立新目标 = 开一个新循环。
- **它们本身不负责验证和安全兜底** —— 这块由探索模式的 RSI 闭环补上(冻结评估器 + 留出集 + 晋升门 + 回滚)。
- **它们需要授权。** Musk 能质疑任何要求,因为他是创始人。
- **"让设备一直跑"不等于不许停。** 局部可以停(一个方向该关就关),全局不停(总得有东西在跑);但**目标死了就全停**。

### 什么时候不该用这套

| 场景 | 为什么不行 |
|---|---|
| 和人相关且不可逆的事(裁员、绩效、对外承诺) | 删不回来,且"质疑+删除"会直接伤人 |
| 需要多方共识的决策(跨部门、对外合作) | 单方面删除会变成政治事故 |
| 安全关键 / 强监管系统 | "疯狂删除"要换成可逆性分级 + 强制留出集 |
| 目标本身还没定 | 先定目标(减法第 0 步)或参照系(探索第 1 步) |

## 常见反模式(按模式归类)

### 通用(两种模式都会犯)

| 反模式 | 表现 | 后果 |
|---|---|---|
| 设备空转 | 等上一组结果才排下一组 | 吞吐腰斩 |
| 卡住就全员停 | 一个方向失败就干等 | 时间白流,团队熄火 |
| 跑完没下一轮 | 实验做完没产出下一步假设 | 这次实验白跑 |
| 改裁判 | 改测试 / 门禁让它通过 | **分数彻底失去意义** |
| 看见测试 | 拿留出集反复调参 | 过拟合,上线就崩 |
| 没进 gate 就宣称改进 | "我感觉变好了" | 自欺,无法复现 |
| 不回滚 | 留下半成品和注释掉的代码 | 下一轮基线不可信 |
| 建审同人 | 自己提议自己打分 | 盲区永远存在 |
| 没有停止条件 | 一直在跑,永远没有结论 | 不收敛,烧到没钱才停 |
| 无预算闸 | 不设时间 / 成本 / 轮次上限 | "代价超价值"无法判定 |
| 在错误场景用这套 | 该用探索却用减法(或反之) | 删错东西 / 永不收敛 |

### 探索模式(找新东西时犯)

| 反模式 | 表现 | 后果 |
|---|---|---|
| 拿已知解未知 | 在未知领域直接套五步 | 没有要求可质疑,空转 |
| 把约定当物理 | "行业就是这样" | 用别人的边界当自己的边界 |
| 拿样本当结论 | "别人都失败了" | 常见路径失败往往正因它是常见路径 |
| 不可证伪 | 只有信念,没有假设 | 拿不到任何信息 |
| 把换路当停止 | 一个假设死了就全员收工 | 目标还没死,项目先死 |
| 把停止当失败 | 该停不敢停,把收工当认输 | 过度投入,做没人要的东西 |

### 减法模式(造已知东西时犯)

| 反模式 | 表现 | 后果 |
|---|---|---|
| 无目标 / 目标不可测 | 没想清往哪造就开评审 | 质疑没基准,停也停不下来 |
| 顺序颠倒 | 直接跳到优化/自动化 | 优化了垃圾 |
| 不敢删 | "这个以后可能有用" | 系统越来越臃肿 |
| 拿不可逆的东西疯狂删 | 删数据 / 客户 / 对外承诺 | **加不回来** |
| 无署名要求 | "上面要求的" | 无人负责,无法质疑 |
| 在坑里加速 | 流程没理清就催进度 | 加速灾难 |
| 过早自动化 | 流程还在变就上工具 | 固化错误 |

## 一句话记忆

**减法(已知):删。探索(未知):证伪。**

**参照系 → 目标 → 质疑 → 删除 → 简化 → 加速 → 自动化**

**跑起来别停:一个方向不行就换一个 —— 但别让设备空着。**

**改得了裁判,分数就没有意义。**

**停不停,只看目标 —— 不看累不累。**

在未知领域,先问一句:**凭什么你认为是对的?**
