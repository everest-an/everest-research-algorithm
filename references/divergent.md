# 探索模式 · 找可能存在的东西

> 适用:**目标未知** —— 物理 / 新材料 / 模型研发 / 任何"造新东西"。源自第一性原理 + 科学方法 + RSI。
> 共享底座(让设备跑 / 预算闸 / 停止三来源)见 `SKILL.md`。

## 铁律:证伪优先,别急着证明

你不去"证明"一个假设是对的 —— 你设计**最小实验去杀死它**。杀不死的才留下。

---

## 第 1 步 · 参照系(凭什么你认为是对的?)

- 你的判断依据是什么?**说得出依据吗?** 如果依据是"常见路径",那只是一个**样本,不是答案**。
- 是你在设置限制,还是"常见路径"在替你设?把每条限制过一遍:

| 类型 | 例子 | 处理 |
|---|---|---|
| 物理 / 数学不可能 | 光速、热力学、材料强度 | **不可推翻**,接受它 |
| 法律 / 合规硬约束 | 法规、牌照、审批 | **不可无视,但可质疑、可修改、可绕开** |
| 约定约束 | "行业惯例""大家都这么做""别人都失败了" | **不是约束,是默认值**,可以推翻 |

- 未知领域里没人能证明自己是对的。所以你不需要"对",你需要**可被证伪**。

## 第 2 步 · 证伪判据

- 未知领域**没有基准**,所以可测量的东西是「**证伪判据**」—— 能判断这个假设**死没死**的那一个观测。
- **先定它,再开工。** 没有证伪判据的假设不是假设,是信念 —— 信念不产生信息。

## 第 3 步 · 并行提假设

- 一次提**多个**假设,并行去测。串行是最后手段。
- 假设之间要能**互相证伪** —— 如果多个假设给出同一预测,它们没有区分度,合并掉。

## 第 4 步 · 最小实验(去杀死它)

- 设计**能最快杀死假设**的最小实验。不是证明它,是证伪它。
- 在未知领域,加速循环时间的意义就是**更快证伪** —— 不是抢先,是早点知道自己错在哪。

## 第 5 步 · RSI 闭环(让改进可验证)

```
提议 → 评估(冻结评估器) → 晋升门 → 保留 / 回滚 → 记录血缘 → 下一代
```

**七条硬规则:**

1. **评估器不可改。** 改进者不能碰判分规则 —— 测试、门禁、反作弊、循环编排本身,全部冻结。**改得了裁判,分数就没有意义。**
2. **留出集必须封存。** 搜索过程看不到最终测试。看得见的测试,迟早会被拟合。
3. **没进晋升门,不算改进。** "我觉得变好了"不是证据。只有显式 gate 通过才算数,而且只有它能接受候选。
4. **被拒的必须回滚。** 干净退回上一版,不留半成品 —— 半成品会让下一轮的基线不可信。
5. **每代记血缘。** 谁改了哪、依据什么、结果如何,可追溯、可复现。没有血缘 = 复现不了 = 等于没发生。
6. **失败要留下残渣,喂给下一轮。** 失败不是噪声,是下一轮的课程来源。拒绝理由要结构化留存,不是丢掉。
7. **建与审分离。** 提议的人不给自己打分。条件允许就上红队对抗。
   - **单人时怎么办:** 做**时间分离** —— 建完先搁置,隔一段时间(或换个上下文)再以"审"的身份回来;或让另一个 agent / 另一个模型当红队。关键是**不能在同一口气里既提议又通过**。

**判据:这一轮的改进,别人能复现吗?** 能 → 它是真的;不能 → 它只是你的感觉。

## 第 6 步 · 换方向

- 一个假设死了 → **换下一个,不要停**。卡住不是停工理由,是换路信号。
- 卡住时三选一,但别选"等着":

| 出路 | 做什么 |
|---|---|
| 换方向 | 试另一条路径 / 另一组参数 / 另一个假设 |
| 定位问题 | 分层排查:到底是哪一环错了?找到真正那一层 |
| 修,再试 | 修完立刻重跑,别让"修"变成新的等待 |

## 第 7 步 · 止损

- 停止三来源见 `SKILL.md`:**目标(达成 / 被证伪 / 代价超价值) / 不可逆风险 / 预算闸**。

**明确不算停止理由的:**

- "没灵感 / 累了" → 这是**换方向**,不是停。
- "这个方向失败了" → 这是**换路**,不是停。
- 只有**目标本身**出问题(被证伪 / 没意义 / 代价超价值)才停。

**刹车 vs 换路(最容易搞混):**

| 情况 | 动作 | 层 |
|---|---|---|
| 一个方向不行 | **换方向** | 执行层 |
| 目标不可能 / 没意义 | **停**,回第 1 步重立参照系 | 目标层 |
| 代价超价值 | **停**,或降级目标 | 目标层 |
| 目标达成 | **停**,收工 | 目标层 |
